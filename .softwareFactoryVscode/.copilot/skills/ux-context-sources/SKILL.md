# UX Context Sources

Derive UX and workspace-behavior intent from, in order:

1. Implemented runtime and validation behavior
2. `docs/VSCODE-WORKSPACE.md`
3. `README.md` and `docs/INSTALL.md`
4. Existing projected host workspace artifacts

If the documentation and implementation disagree, treat that as a requirement gap and fix the mismatch instead of guessing.
