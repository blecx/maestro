# Skill Template

This is the golden template for all AI Agent skills in the `.copilot/skills/` directory.

<skill>
<name>skill-name-here</name>
<description>Brief 1-sentence description</description>
<file>
# [Skill Name]

## Objective
A 1-2 sentence description of what this skill achieves and its primary domain authority.

## When to Use
- Positive bounds: Use this when the user is asking...
- Trigger phrase: "Trigger me if..."

## When Not to Use
- Negative bounds: Do NOT use this skill when...
- Exclusion: Ignore this if the task is strictly about...

## Instructions
1. Step 1...
2. Step 2...
- Guardrails and actionable rules go here.
</file>
</skill>
